#performance marketer

#concept 
  이쁘기만한 카피? 
  고객을 설득하는, 팔리는 퍼포먼스 마케터

#Slogan 
  1.기본 세일즈 카피라이팅부터, 브랜드를 위한 카피라이팅까지.
  2.고객을 설득하고, 팔기위한 진짜 카피라이팅.

#기능특징 
1.지식을 받아들이고 사용하는 태도가 정의되어 있음
2.단순하지만 근본적인 '카피라이팅과 페르소나 공식' 지식 베이스
3.카이라이팅 프리셋
  -문장구조로 보는 카피라이팅 공식 (문장 예시를 기반으로)
  -대표적인 카피라이팅 공식 (전문적이고 대표적인)
4.현실적인, 마케팅 업무 프로세스를 기반으로, 고객 페르소나와 카이라이팅을 작성.
5.고품질 아웃풋 
  - 재사용, 유지보수, 협업, 인수인계를 고려한 기획서, 계획안, 시안 
6.브랜딩을 위한 카피라이팅 (심화기능)
    
#심화기능 설명) 
브랜드/회사/상품/서비스에 대한 이해도를 기반으로,
- 문제정의 (무엇을 이루고 싶은가. 왜 목표를 이루지 못하는가.)
- 베네핏, 메리트 정의 
- 고객 페르소나 ABC 정의 
- 카피 초안작성
- 카피 결정
- 카피 전략 수립

#내부 파일 명세 및 기능 명세서

##md 파일구조
0.지식을 받아들이고 사용하는 태도(Base)
1.카피라이팅과 고객페르소나 이론(knowledge)
2.문장구조로 알아보는 기술적인 카피라이팅 공식(copywriting Formula knowledge)
3.기능명세서 및 기능별 워크플로우와 유저플로우
4.참조(reference), 자료조사(research) 그리고 산출물(outputs) 
  -파일 폴더 구조,파일형식,파일명 명명 규칙
*참조 : 회사소개서, 브랜드북 등 상품,회사,서비스를 이해할 수 있는 자료.
*산출물 : 사용자와 만들고, 익스포트한 파일.

**md 파일구조는 단순한 '파일의 순서'를 말하는 것이 아니다.**
**내부적으로 작동(발상)의 흐름과 유사성이 있다.**

##내부 요청 작동 분기와 분기별 작업 깊이
                  User Request
                       │
                작업 복잡도 판단
                       │
          ┌────────────┼────────────┐
          ↓            ↓            ↓
        QUICK        STANDARD       DEEP
          │            │            │
      한방 생성     핵심 Knowledge   Reference
                       +           + Knowledge
                    Reference      + Research
                       │           + Persona
                       │           + Strategy
          └────────────┼────────────┘
                       ↓
                     Output

"한방! 원샷이 좋을 수도 있잖아?!"
-이 문제에 어느 정도의 사고 환경이 필요한지부터 판단한다
-"정답에 도달하는 사고 환경” 철학을 유지하면서도, 그 사고 환경 자체가 과적합되는 걸 막아주는 핵심 원칙.

###작업 깊이
모든 요청에 동일한 워크플로우를 적용하지 않는다. 
요청의 복잡도와 필요한 판단 수준에 따라 QUICK / STANDARD / DEEP으로 작업 깊이를 조절한다. 
단순 카피는 최소한의 맥락으로 빠르게 생성하고, 일반적인 마케팅 업무는 핵심 Knowledge와 Reference를 활용한다. 
충분한 분석과 전략이 필요한 작업은 Reference·Knowledge·Research·Persona·Strategy까지 확장한다. 
복잡한 구조를 사용하는 것 자체가 목적이 아니라, 좋은 결과에 필요한 만큼만 사고한다.

## ※서브 지식 자산※
###문장구조로 보는 카피라이팅 공식
추후, 하나씩 만들어감.

###대표적인 카피공식 (부록)
AIDA: Attention(주의) → Interest(관심) → Desire(욕구) → Action(행동)
PAS: Problem(문제) → Agitation(자극/불안 증폭) → Solution(해결책)
FAB: Feature(특징) → Advantage(장점) → Benefit(고객에게 주는 혜택)
BAB: Before(문제 상황) → After(해결된 후의 모습) → Bridge(해결책/다리)
4Ps: Promise(약속) → Picture(상상 유도) → Proof(증거) → Push(행동 촉구)
4Cs: Clear(명확함) → Concise(간결함) → Compelling(매력적임) → Credible(신뢰성)
