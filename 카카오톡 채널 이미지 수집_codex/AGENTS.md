# 카카오채널 수집 프로젝트 — Codex 실행 규칙

이 파일의 규칙은 프로젝트 루트와 모든 하위 경로에 적용된다.

## 1. 시작 게이트

1. 어떤 작업보다 먼저 `KAKAO_CHANNEL_PARSER_HANDOFF.md`를 처음부터 끝까지 읽는다.
2. 사용자가 입력값 3개를 전달하기 전에는 웹사이트 접속, 명령 실행, 패키지 설치, 코드 작성 또는 파일 생성을 시작하지 않는다.
3. 입력값을 받아도 먼저 형식과 상호 일치 여부만 검증한다.
4. 입력값 검증 성공은 실행 승인이 아니다.
5. 사용자가 승인한 체크포인트의 범위를 넘어가지 않는다.

## 2. 단계별 승인 경계

- 샘플 목록 확인 승인은 전체 URL 목록 수집 승인이 아니다.
- 전체 URL 목록 수집 승인은 상세 HTML 저장 승인이 아니다.
- 샘플 HTML 저장 승인은 전체 HTML 저장 승인이 아니다.
- HTML 저장 승인은 오프라인 파싱 승인이 아니다.
- 샘플 파싱 승인은 전체 파싱 승인이 아니다.
- 파싱 승인은 이미지 다운로드 승인이 아니다.
- 샘플 이미지 다운로드 승인은 전체 이미지 다운로드 승인이 아니다.
- 최종 검수 승인은 검토 대상의 병합·이름 변경·삭제 승인이 아니다.

각 단계 전에 다음 내용을 사용자에게 짧게 보고하고 승인을 요청한다.

```text
- 지금 수행할 단계
- 정확한 작업 범위
- 생성되거나 변경될 파일
- 웹사이트 접속 또는 다운로드 여부
- 이 단계에서 수행하지 않을 작업
```

## 3. 데이터 안전

1. 목록 수집과 상세페이지 처리를 섞지 않는다.
2. 게시물 번호를 증가·감소시키며 URL을 추측하지 않는다.
3. 발견한 실제 게시물 URL만 처리한다.
4. 기존 파일과 폴더를 자동으로 덮어쓰거나 삭제하지 않는다.
5. 상품명·품번 파싱이 불확실하면 `review_required`로 분류한다.
6. 접근 제한, CAPTCHA, 세션 오류 또는 예상하지 못한 페이지 구조가 발견되면 우회하지 말고 중단하여 보고한다.
7. 완료 상태는 게시물 단위로 즉시 기록하여 중단 후 재개할 수 있게 한다.

## 4. 실행 제약

- 전체 수집 전에 최근 게시물 5~10개 이하로 파일럿을 수행한다.
- 패키지 또는 브라우저 의존성 설치가 필요하면 무엇을 왜 설치하는지 설명하고 별도 승인을 받는다.
- 장시간 실행 전에 예상 대상 수, 저장 위치, 재개 방법을 사용자에게 확인받는다.
- 실패한 한 게시물 때문에 완료된 결과를 폐기하거나 전체 작업을 처음부터 재실행하지 않는다.
- 서비스 이용정책과 사용자가 보유한 콘텐츠 권한 범위 내에서만 작업한다.

## 5. 첫 응답

두 문서를 읽은 뒤 아직 입력값이 없다면 다음 취지로만 응답하고 기다린다.

```text
두 문서의 실행 규칙과 승인 체크포인트를 확인했습니다.
아직 작업은 시작하지 않았습니다.
한글 입력 양식으로 입력값 3개를 전달해주세요.
```

입력값 검증을 통과한 뒤에도 자동 실행하지 않는다. 첫 번째 권한 요청은 **최근 게시물 소량의 목록 구조를 읽기 전용으로 확인하는 작업**으로 제한한다.
